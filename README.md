🎮 游戏简介
《上班积分任务 · 海盐版》是一款以职场为舞台的成人向露出/寸止挑战游戏，融合了骰子随机、积分经营、惩罚清算与多日养成的养成玩法。玩家扮演一位上班族，执行一系列尺度逐级加深的暴露任务，通过积攒积分换取"奖励"或避免"惩罚"。

🎲 核心玩法
骰子随机 × 主动加码：服装、日常任务、赌局层层递进，每个选择都伴随真实的紧张感
每日循环养成：任务、赌徒挑战、条件事件、惩罚清算环环相扣，一天一局、越玩越深
沉浸式积分记账：暴露、高潮、违规快感一键记录，随时掌控局面

⚙️ 程序特色
完全客户端自定义：赌徒任务池支持玩家自行增删任务，三档池子随你改写，规则掌握在自己手里
存档自由迁移：一键导出存档 JSON、随时导入恢复，换设备不丢进度（本地 localStorage 存储）
最多 5 步撤销、生涯数据统计、内置计时器、震动反馈、18+ 年龄确认门

⚠️ 仅限年满 18 周岁玩家。内容纯属虚构，请量力而行，注意人身安全与隐私。
